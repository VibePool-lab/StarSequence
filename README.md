# StarSequence

A small 3D space mini-game built with Three.js.

## Overview

In **StarSequence**, the player travels through space and collects glowing floating numbers in the correct order from **1 to 10**.

The game combines:

* simple arcade gameplay,
* a relaxing cosmic atmosphere,
* 3D movement,
* mouse-look controls,
* and number-sequence mechanics.

Built entirely with:

* HTML
* CSS
* JavaScript
* Three.js

---

# Features

* 3D space environment
* Thousands of animated stars
* Floating glowing number orbs
* Mouse-look spaceship controls
* Sequential number collection gameplay
* Penalty system for wrong selections
* HUD interface
* Win screen and restart option
* Lightweight single-file structure

---

# Controls

| Action         | Key                            |
| -------------- | ------------------------------ |
| Move Forward   | W                              |
| Move Backward  | S                              |
| Move Left      | A                              |
| Move Right     | D                              |
| Boost Speed    | Shift                          |
| Look Around    | Hold Mouse Button + Move Mouse |
| Collect Number | Click                          |

---

# Objective

Collect the numbers in the correct order:

**1 → 2 → 3 → ... → 10**

Clicking the wrong number adds a time penalty.

# Installation

## Option 1 — Run Locally

1. Download the project files.
2. Open `index.html` in your browser.

---

## Option 2 — Use VS Code Live Server

Recommended for development.

1. Install Visual Studio Code.
2. Install the “Live Server” extension.
3. Right-click `index.html`.
4. Select:

```text
Open with Live Server
```
